# VIEWS – Digitale Ermittlungsakte

Eine interaktive Unterrichtssimulation zu Marc-Uwe Klings Roman *Views*.

## Veröffentlichung mit GitHub Pages

1. Auf GitHub ein neues Repository erstellen, z. B. `views-ermittlungsakte`.
2. Die Dateien `index.html`, `styles.css` und `app.js` in das Repository hochladen.
3. In **Settings → Pages** unter der Veröffentlichungsquelle den Branch `main` und den Ordner `/ (root)` auswählen.
4. GitHub veröffentlicht die Seite unter einer `github.io`-Adresse.

GitHub Pages hostet statische HTML/CSS/JavaScript-Dateien. Für GitHub Free muss das Repository für Pages öffentlich sein.

## Wichtig
Die Seite sammelt keine Formulardaten und sendet keine Antworten an einen Server. Der Fortschritt wird ausschließlich im Browser über `localStorage` gespeichert.

Das bedeutet auch: Die Antworten sind keine echte Sicherheitsfunktion. Wer den Quellcode untersucht, kann die Lösungen theoretisch finden. Für eine Unterrichtssimulation ist das ausreichend, aber es ist kein geschütztes Prüfungssystem.

Die Seite ist eine eigenständige Unterrichtsarbeit und nicht mit dem BKA oder dem Verlag verbunden.

## Inhalt
Die Handlung wird überwiegend paraphrasiert. Es werden keine längeren Originalpassagen aus dem Roman reproduziert. Eigene Textstellen mit Seitenzahlen können für die schulische Präsentation ergänzt werden.
